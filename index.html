🔄 기기·브라우저 간 동기화

과제 체크 · API 키 · 속도/목소리 · 연습 기록을 본인 GitHub의 비공개 메모(Gist)에 저장해서, 사파리·Edge·PC 어디서 열어도 똑같이 맞춰요. 브라우저마다 토큰을 한 번만 넣으면 돼요.

토큰 만들기 (1분)

  1. 여기를 눌러 GitHub 토큰 만들기 화면 열기 (이름·권한이 미리 채워져 있어요: gist만)
  2. Expiration(만료)을 No expiration 또는 1년으로 고르기
  3. 맨 아래 Generate token → 나온 토큰(ghp_로 시작) 복사
  4. 아래 칸에 붙여넣고 [저장하고 동기화]

토큰은 이 브라우저에만 저장되고 동기화되지 않아요. gist 권한만 있어서 코드나 레포는 건드릴 수 없어요.

🔑 AI 발음 분석 (Gemini API)

키를 넣으면 말하기 테스트를 녹음해서 Gemini가 직접 듣고 뭉개진 단어 · 강세 · 억양 · 연음 · 문법을 분석해요. 키는 이 기기의 브라우저에만 저장돼요.

키 발급 방법

  1. aistudio.google.com 에 구글 계정으로 로그인
  2. 왼쪽 메뉴 [Get API key] → [Create API key]
  3. 만들어진 키(AIza로 시작)를 복사해서 위 칸에 붙여넣기

AI가 듣고 판단한 연습용 피드백이에요. 공식 점수는 아니에요. 무료 사용량을 넘기면 구글 정책에 따라 제한되거나 요금이 생길 수 있어요.

스크립트 문장을 누르면 그 문단을 1번 1회, 2번 무한 반복, 3번 정지로 읽어요. 전체 화면에서는 질문 대신 한국어 흐름(요약)이 보여서, 보면서 답변 연습을 할 수 있어요. [전체 듣기]를 누르면 전체 화면으로 바뀌어요(닫기: ← 이전, Backspace, 좌우 스와이프). 목표 시간은 선생님 기준으로 모든 답변 60~80초, 최대 2분이에요(⏱ 표시는 자연스러운 속도 분당 150단어 기준 예상 시간). 예상 등급은 암기·전달력 기반의 연습용 추정치이며 실제 OPIc 점수와 다를 수 있어요. 말하기 테스트는 기본적으로 브라우저 음성인식(아이폰은 사파리 권장)을 쓰고, 🔑 API 키를 넣으면 녹음 파일을 Gemini가 직접 듣고 강세·억양·연음·뭉개진 단어까지 분석해요(이 모드는 Edge에서도 돼요). 마이크 권한이 필요해요.
